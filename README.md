# 8bitbrains — Next.js

The 8bitbrains agency site is served from the Next.js App Router at `/`. The original page and its image assets are in `public/` so its existing layout and browser interactions remain intact while the app is migrated incrementally.

## Requirements

- Node.js 20.9 or newer

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

For production, run `npm run build` followed by `npm start`.
